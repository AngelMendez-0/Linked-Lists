# Java Data Structures and Algorithms

## Description
This repository contains implementations of fundamental data structures and algorithms developed in Java.
These projects focus on understanding how data structures work internally and how algorithms can be implemented without relying on built-in libraries.

## File Descriptions

### HW56 – Expression Evaluation Using Stacks
Implementation of postfix and prefix expression evaluation using a custom stack data structure. Demonstrates stack operations and expression parsing techniques.

### HW7 – Hashtable Implementation
Custom hashtable implementation using linked lists for collision handling. Supports insertion (`put`), retrieval (`get`), and removal (`remove`) of key-value pairs. 
Demonstrates hash function design, collision resolution strategies, and use of linked data structures in practical applications.

### HW8 – Linked List Sorting Algorithms
Implementation of Merge Sort and other sorting algorithms using linked list structures. Demonstrates algorithm efficiency and linked data structure manipulation.
